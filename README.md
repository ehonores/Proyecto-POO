# Proyecto de Programación Orientada a Objetos (POO)

Sistema desarrollado en Java que simula la gestión de contenidos audiovisuales aplicando los pilares fundamentales de la POO (herencia, polimorfismo, asociación y agregación).

##  Características del Sistema
* **Jerarquía de Clases:** Implementación de clases abstractas y subclases (Películas, Series, Documentales, Animaciones y Publicaciones de Reddit).
* **Entidades Auxiliares:** Manejo de datos mediante clases de apoyo (`Actor`, `Temporada`, `Investigador`).
* **Colecciones Dinámicas:** Almacenamiento y procesamiento heterogéneo mediante estructuras `ArrayList`.

##  Tecnologías Utilizadas
* **Lenguaje:** Java (JDK 21)
* **Entorno de Desarrollo (IDE):** Eclipse / eclipse 
* **Control de Versiones:** Git y GitHub
